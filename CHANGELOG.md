# История изменений

## Не выпущено

### Изменено

- Sphinx обновлён с 8.2.3 до 9.1.0. Для проектов с `autodoc`, `mathjax` или собственными расширениями проверьте [изменения совместимости Sphinx 9](https://www.sphinx-doc.org/en/master/changes/9.0.html).
- Тема Read the Docs обновлена с 3.0.2 до 3.1.0.
- Зафиксированы версии Python-пакетов, включая транзитивные зависимости, и содержимое базового образа Docker.

### Добавлено

- Добавлена папка `project-template` с шаблоном нового проекта, использующего этот образ.
- Тесты для проверки правильности сборки образа.
- Инструкция по созданию, сборке и предпросмотру проекта документации.

### Исправлено

- Предпросмотр использует образ из `SPHINX_DOCKER_IMAGE`, как и сборки HTML и PDF.
- Сборка образа работает при клонировании через HTTPS. Имя образа можно задать через `IMAGE_NAME`.
- Исправлено отображение и обновление иллюстраций из `src/figures` в предпросмотре.
- Исправлена потеря PDF при параллельном запуске полной сборки `make -j2 all`.
- Отдельная сборка HTML больше не удаляет PDF и другие результаты из `htdocs`.
- Повторная команда `make pdf` обновляет документ после изменения исходников.
- Новый проект из шаблона собирается и открывается в предпросмотре сразу после копирования.
