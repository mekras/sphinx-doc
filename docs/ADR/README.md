# Журнал архитектурных решений

Журнал сохраняет причины значимых архитектурных решений об устройстве образа
Docker и шаблона проекта документации. Он помогает при дальнейшем развитии
проекта понимать рассмотренные варианты и принятые последствия.

## Область журнала

Здесь записываются решения об устройстве образа Docker и шаблона документации,
которые имеют последствия за пределами текущей задачи. Организационные
договорённости и редакторские правки в этот журнал не входят.

## Содержание записи

Запись содержит проблему, решение, обоснование и последствия. Если варианты
сравнивались, запись сохраняет их сравнение. Если варианты не рассматривались
или были исключены заранее известным ограничением, это указывается прямо.

Решение принимает человек до его реализации.

## Статусы

- «Предложено» — решение подготовлено и ожидает рассмотрения.
- «Принято» — человек одобрил решение.
- «Отклонено» — предложение рассмотрено и не принято, причина отказа сохранена.
- «Устарело» — решение утратило актуальность.
- «Заменено» — принято другое решение, в записи указана ссылка на него.

## Имена файлов

Записи хранятся в этой папке под именами `ADR-0001.md`, `ADR-0002.md` и далее.
Идентификатор записи — `ADR-NNNN`. Номера не переиспользуются.

ссылку на файл и текущий статус.
